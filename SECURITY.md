# Security reports

For HoH-lite vulnerabilities, follow
[hoh-lite/SECURITY.md](hoh-lite/SECURITY.md). For other security issues in this
repository, use
[private vulnerability reporting](https://github.com/Flesymeb/HarnessOfHarness/security/advisories/new)
if available. Otherwise, open an issue requesting a private contact channel;
do not include exploit details or credentials in that issue.
