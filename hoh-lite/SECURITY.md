# Security reports

For a vulnerability in HoH-lite, use GitHub's
[private vulnerability reporting](https://github.com/Flesymeb/HarnessOfHarness/security/advisories/new)
for the HarnessOfHarness repository. If that form is unavailable, open an
issue asking maintainers for a private contact channel without including
exploit details, credentials, or private data.

For ordinary bugs, use a public issue with a minimal reproducible example.
