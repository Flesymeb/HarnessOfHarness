### Generic playability

- Establish that the project starts without a blocking parse, import, or runtime error.
- Exercise the primary public interaction with ordinary input and observe a visible state change.
- Preserve already-working controls and player-visible behavior when repairing another surface.
- Treat screenshots as visual evidence and runtime state/logs as behavioral evidence; neither alone proves every claim.
- End a test route at an observable success, failure, score, or progression state when the public task defines one.
